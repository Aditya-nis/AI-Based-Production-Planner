1. Constraint Satisfaction Problem (CSP)

A CSP is mathematically formalized as a triple $\langle X, D, C \rangle$:

  • $X = \{X_1, X_2, \dots, X_n\}$: Finite set of variables.
  • $D = \{D_1, D_2, \dots, D_n\}$: Domain of admissible values for each variable.
  • $C = \{C_1, C_2, \dots, C_m\}$: Set of constraints restricting allowable simultaneous value combinations.

A state is consistent if it violates no constraints. A solution is a complete, consistent assignment to all variables.

2. Minimum Remaining Values (MRV)

Also known as the "Most Constrained Variable" or "Fail-First" heuristic:

Task A → 5 legal slots remaining
Task B → 2 legal slots remaining
Task C → 7 legal slots remaining
⇒ MRV selects Task B first!

Why? By choosing the variable most likely to cause an early failure, we prune invalid search subtrees high up in the tree, minimizing overall search iterations.

3. Backtracking Search Algorithm

Standard Depth-First Search for CSPs that incrementally builds candidates:

  1. If current assignment is complete, return success.
  2. Pick an unassigned variable using MRV.
  3. Iterate through domain values (ordered by earliest start time).
  4. If consistent with current assignment: assign variable = value, forward check, recurse.
  5. If recursion succeeds, return solution; otherwise backtrack.
4. Forward Checking (Inference)

Forward checking keeps track of remaining legal values for unassigned variables as assignments are made:

  • Whenever variable $X$ is assigned value $v$, inspect every unassigned variable $Y$ connected to $X$ by a constraint.
  • Delete any value from $Domain(Y)$ that violates a constraint with $(X = v)$.
  • If any $Domain(Y)$ becomes empty, immediately trigger backtracking without exploring fruitless branches deeper.

Viva Guide

For $N$ tasks and domain size $D$, brute force generates $D^N$ combinations (combinatorial explosion). With $N=10$ and $D=20$, $20^{10} \approx 10^{13}$ states. Backtracking with MRV detects conflicts immediately after the first invalid assignment, pruning millions of invalid branches before visiting them, reducing execution time to under 5 milliseconds.

When an asset status changes to 'Maintenance' (Hard Constraint 9), the CSP engine dynamically eliminates that machine from all variable domains during domain generation. Running "Regenerate Plan" solves the CSP with remaining available machines and workers without code modifications.

Priorities (High, Medium, Low) act as a secondary heuristic (tie-breaking in MRV variable selection and value ordering). High-priority tasks are selected earlier in ties and assigned earlier time slots, while still strictly satisfying all 10 hard constraints.

In the theoretical worst case, Backtracking search is $O(d^n)$, where $n$ is the number of variables and $d$ is the maximum domain size. However, with the MRV heuristic, early constraint checking, and forward checking, the effective branching factor is drastically reduced, enabling real-time convergence on standard shopfloor instances.

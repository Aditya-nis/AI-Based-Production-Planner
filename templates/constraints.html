10 HARD CONSTRAINTS ENFORCED
1. Machine Temporal Non-Overlap
HARD CONSTRAINT

A machine cannot process two production tasks at the same time.

∀ i ≠ j, (M(Ti) = M(Tj)) ⇒ [Start(Ti), End(Ti)) ∩ [Start(Tj), End(Tj)) = ∅
2. Worker Temporal Non-Overlap
HARD CONSTRAINT

A worker cannot work on two production tasks at the same time.

∀ i ≠ j, (W(Ti) = W(Tj)) ⇒ [Start(Ti), End(Ti)) ∩ [Start(Tj), End(Tj)) = ∅
3. Machine Technical Compatibility
HARD CONSTRAINT

A product can only be assigned to a machine matching its required type.

Type(M(Ti)) = RequiredType(Ti)
4. Worker Skill Qualification
HARD CONSTRAINT

An operator assigned to a task must hold the certified skill required.

Skill(W(Ti)) = RequiredSkill(Ti)
5. Machine Working Hours Capacity
HARD CONSTRAINT

Total scheduled operating hours on any machine cannot exceed daily capacity.

∑T ∈ Assigned(M) Duration(T) ≤ MaxAvailableHours(M)
6. Worker Working Hours Limit
HARD CONSTRAINT

Total assigned task hours for an operator cannot exceed daily shift hours.

∑T ∈ Assigned(W) Duration(T) ≤ MaxAvailableHours(W)
7. Raw Material Availability
HARD CONSTRAINT

Required raw material stock must be sufficient before authorizing production.

∑T ∈ Scheduled MaterialDemand(T, R) ≤ StockQuantity(R)
8. Production Delivery Deadline
HARD CONSTRAINT

Every scheduled task must complete on or before the specified delivery deadline.

End(Ti) ≤ Deadline(Ti)
9. Machine Active Status
HARD CONSTRAINT

Machines in 'Maintenance' or 'Unavailable' status cannot be assigned.

Status(M) = "Available"
10. Worker Active Status
HARD CONSTRAINT

Workers on 'Leave' or 'Unavailable' status cannot be assigned.

Status(W) = "Available"

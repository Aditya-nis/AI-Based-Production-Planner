Credential Security Policies
  • Zero Plaintext Storage
    Passwords are never saved in plaintext; they are transformed via irreversible cryptographic one-way hashes.
  • Salted Hashes with Scrypt/PBKDF2
    Every password utilizes a random unique salt to prevent rainbow table and dictionary attacks.
  • No Public Registration
    Public visitor registration is strictly turned off. Only logged-in administrators can create operators.
  • Active Session Regeneration
    Updating credentials updates active session metadata immediately without session hijacking risk.
Recommended Best Practice

When deploying publicly to Vercel or production hosting, change the default admin123 password immediately to a strong custom passphrase with letters, numbers, and symbols.
